
## Задание 3 — Галактики

### Что делала программа:
Выводит список галактик с их названием, расстоянием и типом.

### Найденный баг:
В конструкторе GType в операторе switch был указан символ 'l' 
(маленькая буква L) вместо 'I' (заглавная буква I) для типа Irregular.
Из-за этого галактика Small Magellanic Cloud не получала тип Irregular.
Баг был исправлен на 'I'.

### Использованные средства отладки Visual Studio:
- **Точки останова (Breakpoints)** — на строке foreach, на 
  Console.WriteLine внутри цикла, и на switch в конструкторе GType
- **Пошаговое выполнение (Step Over, F10)** — проходил по циклу 
  строка за строкой
- **Окно локальных переменных (Locals)** — раскрывал объект 
  theGalaxy и смотрел значения Name, MegaLightYears, GalaxyType 
  на каждой итерации
- **Подсказки по данным (DataTips)** — наводил мышь на переменные 
  чтобы быстро увидеть их значение
- **Окно стека вызовов (Call Stack)** — отслеживал порядок вызовов 
  Main → IterateThroughList → GType
