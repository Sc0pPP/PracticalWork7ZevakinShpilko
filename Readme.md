## Задание 4 — Буквы

### Что делала программа:
Программа берёт массив букв, на каждом шаге цикла добавляет 
букву к строке name и вызывает метод SendMessage, который выводит 
приветствие с накопленным именем и счётчиком.

### Использованные средства отладки Visual Studio:
- **Точки останова (Breakpoints)** — на строке for, на name += letters[i],
  на вызове SendMessage и внутри самого метода SendMessage
- **Пошаговое выполнение (Step Over, F10)** — проходил по циклу 
  строка за строкой
- **Шаг с заходом (Step Into, F11)** — заходил внутрь метода 
  SendMessage чтобы отследить выполнение
- **Окно локальных переменных (Locals)** — наблюдал как переменная 
  name накапливает буквы по одной на каждой итерации
- **Подсказки по данным (DataTips)** — наводил мышь на letters[i], 
  name, a[i] чтобы видеть текущие значения
- **Окно контрольных значений (Watch)** — добавил переменную name 
  в Watch чтобы следить за ней на протяжении всего цикла
