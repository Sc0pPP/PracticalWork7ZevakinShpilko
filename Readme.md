 Задание 2 — Фибоначчи

 Использованные средства отладки Visual Studio:
-Точки останова(Breakpoints) — расставлял точки на строки
  внутри цикла и на return, чтобы остановить выполнение
- Пошаговое выполнение (Step Over, F10) — проходил по коду
  строка за строкой и наблюдал как меняются n1, n2, sum
- Окно локальных переменных (Locals) — отслеживал текущие
  значения переменных n1, n2, sum, i на каждом шаге цикла
- Подсказки по данным (DataTips) — наводил мышь на переменные
  прямо в коде чтобы быстро увидеть их значение
